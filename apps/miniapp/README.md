# Олимпиадный навигатор — мини-приложение для MAX

Фронтенд «Олимпиадного навигатора» по `Ar.pdf`. Каталог, карточка, «Мой сезон» и настройки
доступны в браузере как демонстрация. В режиме разработки запросы перехватывает MSW;
названия и сроки карточек **вымышлены** и не являются официальным датасетом сезона
2026/27.

## Запуск

```powershell
pnpm install
pnpm dev
```

Откройте `http://localhost:5173`. Для проверки сборки: `pnpm build`.

## Подключение бэкенда

В продакшене моки отключены. Все запросы уходят на `/api`; необработанные ошибки
показываются на экране. Клиент ожидает маршруты из PDF: `GET /api/olympiads`,
`GET /api/olympiads/:id`, `GET/PUT/DELETE /api/me`, `GET/POST /api/me/subscriptions`,
`PATCH /api/me/subscriptions/:id`.

Клиент добавляет исходную строку `window.WebApp.initData` в заголовок `X-Max-Init-Data`
каждого запроса. Бэкенд должен **проверять подпись initData** и определять пользователя
только после проверки. Точное имя заголовка и JSON-формы ответа нужно закрепить в OpenAPI
вместе с Backend. Ожидаемые типы временно описаны в `src/types.ts`. Ожидается, что
`GET /api/olympiads` возвращает массив олимпиад, а `GET /api/me/subscriptions` - массив
подписок. Даты - ISO 8601 с часовым поясом.

Для запуска демонстрационных данных в собранной версии задайте `VITE_DEMO_MODE=true` при
сборке. Для боевого приложения оставьте `false`. `VITE_BOT_NAME` - имя бота без `@`,
используется для ссылки `https://max.ru/<bot>?startapp=<id>`. Не записывайте токены в
`VITE_` переменные: они попадают в браузерный код.

MAX Bridge подключается через официальный скрипт в `index.html`. Используются `initData`,
`start_param`, `BackButton`, `HapticFeedback`, `openLink`, `shareMaxContent` и
`DeviceStorage`; вне MAX предусмотрены браузерные варианты для просмотра и хранения
фильтров. На веб-клиенте MAX часть методов Bridge недоступна - интерфейс остаётся
работоспособным.

## HTTPS и размещение

Собранное приложение (`apps/miniapp/dist`) отдаёт сервер по адресу `/app`, поэтому мини-приложение
и API работают на одном домене. Docker-образ сервера собирает мини-приложение сам, ник бота для
ссылок «Поделиться» передаётся аргументом сборки `VITE_BOT_NAME` (в compose — из `BOT_USERNAME`).
HTTPS на своём домене даёт Caddy из `deploy/Caddyfile`: он проксирует все запросы на сервер.
Адрес `https://<домен>/app` указывается в настройках бота на платформе MAX.
