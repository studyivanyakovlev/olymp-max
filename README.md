# Олимпиадный навигатор

Чат-бот в мессенджере MAX с подключённым мини-приложением. Помогает школьнику 8–11 класса не пропустить регистрацию и туры олимпиад из Перечня РСОШ: подбирает олимпиады по классу и предметам, показывает ближайший дедлайн и присылает напоминания о регистрации и турах.

Проект для трека «Образовательные решения» хакатона MAX.

- Бот в MAX: [max.ru/se13550458_1_bot](https://max.ru/se13550458_1_bot)
- Мини-приложение: открывается из бота; в браузере — [olymp.quiet-harbor.xyz/app](https://olymp.quiet-harbor.xyz/app)

## Назначение

Регистрация на олимпиады открывается на несколько недель, сроки у каждой олимпиады и у каждого профиля свои, а информация разбросана по сайтам организаторов. Школьник узнаёт о регистрации, когда она уже закрыта. Бот собирает сроки в одном месте и напоминает о них в мессенджере, которым школьник и так пользуется.

Проблему подтвердил опрос 28 студентов 1–2 курса о школьных годах: 16 из них пропускали регистрацию на нужную олимпиаду, и 13 из этих 16 — потому что знали срок, но забыли о нём. Итоги и ответы — в [research/survey-2026-09-29.md](research/survey-2026-09-29.md).

## Основной сценарий

1. Школьник открывает бота в MAX и нажимает «Начать» (или отправляет `/start`).
2. Выбирает класс, предметы и регион — три шага на кнопках.
3. Получает персональную подборку: олимпиады его класса по выбранным предметам. В каждой карточке указан ближайший дедлайн, например «⏰ Регистрация на первый тур — до 10 октября, 23:59 (МСК)». Олимпиады с закрытой регистрацией в подборку не попадают.
4. Нажимает «🔔 Подписаться на напоминания». Бот ставит в очередь напоминания: об открытии регистрации, за 3 дня и за 1 день до её конца, за день до тура. Напоминания приходят днём, с 09:00 до 21:00; тихие часы можно сузить или отключить в настройках.
5. В напоминании есть кнопки «✅ Зарегистрировался», «⏰ Напомнить завтра», «❌ Не участвую» и ссылка на регистрацию. После «Зарегистрировался» напоминания о регистрации отменяются, о турах — остаются.
6. Каталог со всеми олимпиадами, фильтрами и разделом «Мой сезон» открывается в мини-приложении кнопкой «🚀 Каталог в Mini App». Кнопка «📱 Открыть в Mini App» в карточке открывает мини-приложение сразу на этой олимпиаде.

## Состав и архитектура

Модульный монолит на Node.js и TypeScript. Один процесс обслуживает бота, REST API для мини-приложения и планировщик напоминаний; все они работают с общими доменными сервисами и одной базой PostgreSQL.

```text
apps/
  server/          # бот MAX, REST API, планировщик напоминаний
    src/bot/       # сценарии бота, клавиатуры, клиент MAX Bot API
    src/api/       # REST API (Fastify), раздача Mini App, вебхук, playground
    src/domain/    # подборка, напоминания, проверка initData, даты
    src/scheduler/ # очередь напоминаний: раз в минуту отправляет наступившие
    certs/         # корневой сертификат Минцифры для TLS-соединения с MAX Bot API
  miniapp/         # мини-приложение: React, Vite, MAX UI, MAX Bridge
packages/
  shared/          # общие zod-схемы контракта API
data/              # olympiads.json, demo.json, schema.json
deploy/Caddyfile   # HTTPS на своём домене (необязательно)
```

- **Бот** получает обновления от MAX через long polling (`BOT_MODE=polling`) или вебхук (`BOT_MODE=webhook`). В режиме вебхука сервер сам регистрирует адрес `${PUBLIC_URL}/webhook` с секретом и отклоняет запросы без него.
- **Мини-приложение** собирается в `apps/miniapp/dist` и отдаётся сервером по адресу `/app`. Пользователя сервер определяет только по подписанной строке `WebApp.initData` из MAX Bridge (HMAC-SHA256 с токеном бота).
- **Планировщик** раз в минуту выбирает наступившие напоминания, отправляет их и делает до трёх попыток при ошибке.

## Запуск в Docker

Нужны Docker и Docker Compose v2.

```bash
cp .env.example .env
docker compose up -d --build
```

Команда собирает образ сервера вместе с мини-приложением и поднимает PostgreSQL. При первом старте сервер сам загружает датасет олимпиад. Проверка: `http://localhost:3000/api/health` возвращает `{"status":"ok",...}`.

С файлом `.env.example` бот работает в локальном режиме с тестовым токеном: к MAX не подключается, а сообщения и напоминания пишет в лог (`docker compose logs -f app`). Сценарий бота можно пройти в браузере на странице `http://localhost:3000/playground`. Чтобы подключить настоящего бота, укажите в `.env` токен `BOT_TOKEN` и ник `BOT_USERNAME`.

HTTPS на своём домене: укажите `PUBLIC_DOMAIN` и `PUBLIC_URL=https://<домен>` в `.env` и запустите `docker compose --profile https up -d --build`. Caddy получит сертификат Let's Encrypt и будет проксировать все запросы на сервер.

### Остановка и повторный запуск

```bash
docker compose stop            # остановить, данные сохраняются
docker compose up -d           # запустить снова
docker compose down            # удалить контейнеры, база сохраняется в томе postgres_data
docker compose down -v         # удалить контейнеры и базу; при следующем старте датасет загрузится заново
```

## Запуск без Docker

Нужен Node.js 22.19 или новее.

```bash
npm ci
cp .env.example .env
npm run dev
```

`npm run dev` сам собирает общий пакет `packages/shared`. Если `DATABASE_URL` пуст, используется встроенный PGlite (PostgreSQL в процессе, каталог `~/.olymp_max_pglite` или `PGLITE_DIR`). Мини-приложение отдаётся по `/app` после `npm run build:app`; для разработки интерфейса есть `npm run dev:app` (Vite на порту 5173, запросы `/api` проксируются на 3000).

## Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `BOT_TOKEN` | для работы в MAX | Токен бота MAX. Пустое значение или префикс `test_` — локальный режим без подключения к MAX. |
| `BOT_USERNAME` | нет | Ник бота без `@`. Сервер получает его из `GET /me`; переменная — запасной вариант и ник для ссылок «Поделиться» в мини-приложении. |
| `BOT_MODE` | нет | `polling` (по умолчанию) или `webhook`. |
| `PUBLIC_URL` | для `webhook` | Публичный HTTPS-адрес сервера. |
| `WEBHOOK_SECRET` | нет | Секрет вебхука; если не задан, выводится из токена бота. |
| `MINIAPP_URL` | нет | Адрес мини-приложения (`https://<домен>/app`), его же указывают в настройках бота на платформе MAX. |
| `PORT` | нет | Порт HTTP-сервера, по умолчанию 3000. |
| `HOST` | нет | Адрес, на котором слушает сервер, по умолчанию `0.0.0.0`. За nginx — `127.0.0.1`. |
| `DATABASE_URL` | нет | Строка подключения к PostgreSQL. В Docker задаётся автоматически. |
| `PGLITE_DIR` | нет | Каталог встроенной базы PGlite, если `DATABASE_URL` пуст. |
| `DEMO_MODE` | нет | `true` (по умолчанию) загружает демо-олимпиаду для проверки жюри. |
| `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB` | нет | Учётные данные PostgreSQL в Docker. |
| `PUBLIC_DOMAIN` | для профиля `https` | Домен, на который Caddy получает сертификат. |

Настоящие значения хранятся только в `.env`, файл в git не попадает. В репозитории лежит `.env.example` с тестовыми значениями.

## Зависимости

Версии зафиксированы в `package-lock.json`. Основные библиотеки:

- сервер: `@maxhub/max-bot-api` (MAX Bot API), `fastify` и `@fastify/swagger`, `pg`, `@electric-sql/pglite`, `undici`, `zod`, `ajv`;
- мини-приложение: `react`, `react-router-dom`, `@maxhub/max-ui`, `lucide-react`, `vite`, `msw` (моки только в режиме разработки);
- тесты: `vitest`.

Все библиотеки распространяются по свободным лицензиям.

## Внешние сервисы и интеграции

- **MAX Bot API** (`https://platform-api2.max.ru`) — получение сообщений и отправка ответов и напоминаний. Нужен токен бота с платформы для бизнеса MAX. Сертификат сервера выпущен удостоверяющим центром Минцифры, которого нет в стандартном хранилище Node.js, поэтому для запросов к MAX сервер добавляет корневой сертификат из `apps/server/certs`. Проверка TLS не отключается.
- **MAX Bridge** (`https://st.max.ru/js/max-web-app.js`) — скрипт в мини-приложении: подпись пользователя, кнопка «Назад», вибрация, открытие ссылок, «Поделиться», хранение фильтров.
- **Публичный HTTPS-адрес мини-приложения.** MAX открывает мини-приложение по адресу, указанному в настройках бота, поэтому для проверки в MAX сервер должен быть доступен по HTTPS. В Docker на локальной машине этот шаг не воспроизводится: мини-приложение открывается в браузере по `http://localhost:3000/app` от имени тестового пользователя. С настоящим токеном без подписи MAX открывается только каталог.

Других внешних систем нет: данные об олимпиадах лежат в репозитории.

## Данные

- `data/olympiads.json` — 24 профиля олимпиад из проекта Перечня олимпиад школьников на 2026/27 учебный год. Даты этапов собраны вручную по календарю olimpiada.ru и сайтам организаторов на 29.09.2026. Это не интеграция с внешней системой. Источник каждой записи — в полях `url` и `source_url`, подробности — в [data/README.md](data/README.md).
- `data/demo.json` — **тестовая демо-олимпиада** для проверки жюри, реальной олимпиадой не является. Первое напоминание по ней приходит через минуту после подписки.
- `data/schema.json` — JSON Schema датасета. Сервер проверяет файлы по схеме при импорте.
- `research/` — итоги опроса о пропущенных регистрациях и ответы без служебных полей формы.

Про пользователя хранятся только класс, предметы, регион, часовой пояс, тихие часы, подписки и очередь напоминаний. ФИО и телефон не запрашиваются. Команда `/delete` в боте и кнопка удаления профиля в мини-приложении удаляют все данные пользователя.

### Тестовые данные

- Датасет загружается при первом старте сервера, если таблица олимпиад пуста. Повторный импорт: `npm run seed` (или `docker compose down -v` и новый запуск).
- Демо-олимпиада помечена «⚡ [ДЕМО ДЛЯ ЖЮРИ]» и всегда стоит первой в подборке. Отключается переменной `DEMO_MODE=false`.
- В локальном режиме (тестовый `BOT_TOKEN`) API определяет пользователя по заголовку `X-User-Id`, а playground создаёт тестового пользователя `web_user_NNNN`. С настоящим токеном API принимает только подписанный `initData`, а playground работает только с тестовыми пользователями `web_user_*` и ничего им не отправляет.

## Пошаговая проверка

**В MAX** ([max.ru/se13550458_1_bot](https://max.ru/se13550458_1_bot)):

1. Откройте бота и нажмите «Начать». Ожидается приветствие и выбор класса.
2. Выберите «10 класс», затем «📐 Математика» и «➡️ Готово», затем регион «Москва». Ожидается сообщение «Настройка завершена» и несколько карточек олимпиад. Первая — демо-олимпиада, у каждой карточки есть строка с ближайшим дедлайном.
3. В карточке демо-олимпиады нажмите «🔔 Подписаться на напоминания». Ожидается ответ «Подписал на … Создано напоминаний: 1».
4. Подождите 1–2 минуты. Ожидается напоминание «⚡ [ДЕМО ДЛЯ ЖЮРИ] Напоминание по олимпиаде!» с названием этапа, датой окончания регистрации и кнопками.
5. Нажмите «✅ Зарегистрировался». Ожидается подтверждение; в разделе «📅 Мои дедлайны» (или `/my`) статус меняется на «✅ Зарегистрирован».
6. Подпишитесь на реальную олимпиаду, например «Физтех» по математике. Ожидается «Создано напоминаний: N», где N больше нуля; в «Мои дедлайны» видна дата ближайшего напоминания.
7. Нажмите «🚀 Каталог в Mini App». Ожидается каталог олимпиад с фильтрами по предмету, классу, уровню и формату. В разделе «Мой сезон» видны подписки из шага 3 и 6. Кнопка «🌐 Открыть каталог в браузере» открывает тот же каталог вне MAX, но без личного раздела.
8. Отправьте `/delete` и подтвердите. Ожидается сообщение об удалении; `/my` показывает, что подписок нет.

**Локально в Docker**, без токена MAX:

1. `docker compose up -d --build`, затем откройте `http://localhost:3000/playground`.
2. Пройдите шаги 1–3 кнопками в окне чата.
3. Отправьте команду `/tick` — планировщик сразу обработает очередь. Текст напоминания появится в `docker compose logs app` в строке «📨 [Эмуляция отправки сообщения]».
4. Каталог мини-приложения: `http://localhost:3000/app`, документация API: `http://localhost:3000/docs`.

Автотесты: `npm test` (проверка датасета, тихие часы, подпись initData, подборка, тексты и очередь напоминаний).

## Известные ограничения

- В датасете 24 профиля олимпиад: только те, у которых на 29.09.2026 опубликованы даты. Нет ВсОШ (даты этапов зависят от региона) и олимпиад без опубликованного расписания. Даты нужно сверять и обновлять вручную.
- Регион сохраняется в профиле, но пока не влияет на подборку: в датасете нет региональных этапов.
- Мини-приложение в MAX работает только по постоянному HTTPS-адресу, указанному в настройках бота. При смене адреса его нужно обновить на платформе MAX.
- Уровни олимпиад указаны по действующему Перечню 2025/26: Перечень на 2026/27 ещё не утверждён.
- Сроки напоминаний считаются по московскому времени; другой часовой пояс пока выбрать нельзя.
