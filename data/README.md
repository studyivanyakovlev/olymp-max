# Данные об олимпиадах

`olympiads.json` — 24 профиля олимпиад из проекта Перечня олимпиад школьников на 2026/27 учебный год. Данные собраны вручную 29.09.2026, это не интеграция с внешней системой. `demo.json` — тестовая демо-олимпиада для проверки жюри, реальной олимпиадой она не является.

## Что внутри

- **Одна запись — один профиль олимпиады.** У профилей одной олимпиады разные даты и разные уровни Перечня: например, у «Высшей пробы» 25 профилей.
- **Предметы** — только те, что можно выбрать в боте: математика, информатика, физика, химия, биология, экономика, обществознание.
- **Даты этапов** взяты из календаря [olimpiada.ru](https://olimpiada.ru) на 29.09.2026. Ссылка на страницу олимпиады лежит в `source_url` каждой записи, сайт организатора — в `url`. Время не публикуется, поэтому этап начинается в 00:00 МСК и заканчивается в 23:59 МСК.
- **Уровни (`rsosh_level`)** — по действующему Перечню на 2025/26 учебный год (приказ Минобрнауки России № 669 от 30.08.2025, таблица на [rsr-olymp.ru](https://rsr-olymp.ru)). Итоговый Перечень на 2026/27 ещё не утверждён, уровни в нём могут измениться.

## Чего нет и почему

- **Олимпиады без опубликованных дат.** На 29.09.2026 в календаре нет расписаний «Ломоносова», олимпиады СПбГУ, «Покори Воробьёвы горы!», «Курчатова», «Технокубка», Турнира городов и ещё нескольких крупных олимпиад. Они будут добавлены, когда организаторы опубликуют даты.
- **Всероссийская олимпиада школьников (ВсОШ).** Даты её этапов зависят от региона. Этапы для Москвы запланированы после онлайн-этапа хакатона.

Регистрация на «Высшую пробу» закрылась 22.09.2026. Записи оставлены, потому что по ним идут напоминания о турах для тех, кто успел зарегистрироваться.

## Как обновлять

1. Поправить `olympiads.json`: даты в ISO 8601 с часовым поясом, `verified_at` — дата сверки.
2. Проверить файл по схеме `schema.json`: `npm test`.
3. Перезапустить импорт: `npm run seed`.
